# 大肥鱼 as a Live2D model

`index.html` + `scene.js`: the agents' character, 大肥鱼 (DeepSeek whale-girl maid), as a Live2D
model, embedded by `lib/widgets/live2d_figure_web.dart`. Query parameters and the message API are
described at the top of `scene.js`.

## Moods, states and reactions

| Message | What she does |
| --- | --- |
| mood `neutral` | her resting face |
| mood `smile` | `ParamMouthForm` +0.6 |
| mood `stern` | brows lowered and angled in, mouth turned down (parameters, no expression file) |
| mood `angry` | `生气` (knitted brows, pout) + `阴暗` (dark face) |
| mood `happy` | `开心兴奋` (^^ eyes, wide smile) |
| state `idle` | breathing, blinking and hair physics (the framework's own) |
| state `listening` | head tilted toward the speaker, leaning in a little |
| state `thinking` | head tilted the other way and up, eyes up and aside |
| state `speaking` | mouth (`ParamMouthOpenY`) opens and closes unevenly, small nod |
| `wave` | `喵喵手~喵~动画` (cat paws out) + `love` (hearts) with the model's `idle` motion moving them, once for 4.4 s; then the motion is stopped and its pose cleared |
| react `surprised` | `感叹号` + raised brows, 1.6 s |
| react `happy` | `开心兴奋` + `love` (hearts) + `脸红`, 2.4 s |

By default she holds the menu board and pen (`点菜按下` + `画笔`), as in the author's design;
`?props=0` drops them. Looks fade in and out; a reaction outranks the mood, the mood outranks the
props, one writer per parameter.
