# UX：舞台式主界面（v3，手绘稿 `随意.pdf` + Gemini / NotebookLM 风格）

**规则：布局按 PDF；v3 起用户同意加入第 5 节的体验增补。** 视觉语言见 [DESIGN.md](DESIGN.md)（Gemini / NotebookLM）。接口见 [api-contract.md](api-contract.md) §5。

PDF 之外的页面（图鉴、打卡页、开场设定、课程生成设置页）已删除。打卡在对话里完成（「오늘 하루 어땠어요?」），建课程也在对话里完成（「수학 공부하고 싶어」）。

## 1. 骨架

两种布局：

```
scene 1、2（两栏）                      scene 4、4-1、5（三栏）
┌────────┬──────────────────────┐      ┌────────┬────────────────┬─────────┐
│ 角色属性栏│                      │      │ 角色属性栏│                │ history │
│ ▭▭▭    │        舞台           │      │ ▭▭▭    │      舞台       │ ─────   │
├────────┤                      │      ├────────┤                │ ─────   │
│ today's │                      │      │ today's │                │         │
│ summary │                      │      │ summary │                │         │
│ sleep:  │                      │      │ sleep:  │                │         │
│ diet:   │                      │      │ diet:   │                │         │
│ diary:  │                      │      │ diary:  │                │         │
│ ◎       │ [⊕  …            →] ∿ │      │ ◎       │ [ …         →] ∿│         │
└────────┴──────────────────────┘      └────────┴────────────────┴─────────┘
```

### 1.1 左栏（所有场景都一样）

- **角色属性栏**：三条横条。依次是 `Lv`（到下一级的进度，每掌握 5 个节点升一级）、`클리어`（已掌握 / 全部节点）、`컨디션`（normal 满、low 半且红、unknown 空）。每条只有一个小标签和条本身。
- **today's summary**：今天（KST）的打卡。`수면`、`식사`、`일기`（transcript 前两行）。没打卡时三项都显示 `—`。
- **◎ 左下角**：设置按钮。PDF 没写里面有什么，目前只放 tooltip `설정 (준비 중)`，不做菜单。

### 1.2 右栏 history（只在 scene 4、5）

| 场景 | 内容 |
|---|---|
| scene 4 | 这个节点的历次审计：日期 · 통과/실패 · 점수 |
| scene 5 | 对话记录（一条长对话，按日期分隔） |

scene 4-1（审计）没有右栏（2026-10-06 改）：整场问答就在舞台中间那一列里，右栏只会重复它。

### 1.3 输入栏

| 场景 | 输入栏 |
|---|---|
| scene 1、scene 5（文字） | `[⊕ 上传] 输入框 [→ 发送]` + 框外 `∿` 语音按钮 |
| scene 2 | `노드 검색…  [→]`，没有其他按钮 |
| scene 4、4-1 | `输入框 [→]` + 框外 `∿` |
| scene 5（语音） | 整条输入栏变成声波，没有按钮 |

- **⊕ 上传**：选一个文件（PDF / TXT / MD），上传后输入框上方出现文件小卡片，和下一句话一起发出。用途：「이걸로 배우고 싶어」→ 用这份文件当大纲生成课程。
- **∿ 语音**：进入 scene 5 语音模式。她听 → 你说完（静音约 1.5 秒）自动发送 → 她说话（TTS）→ 再听。点声波或按 Esc 退出。

### 1.4 窄屏（< 900px）

左栏收进左上角抽屉；右栏收进右上角抽屉。

## 2. 场景

### Scene 1 · 进入画面

```
     🧙‍♀️ ──(🔮 水晶球)          ← 魔法师手托水晶球，球里是当前课程的技能树缩略图；点球 → scene 2

   오늘 하루 어땠어요?  →          ← 推荐句，最多两条（规则见契约端点 20）
   지난번 「판별식」 이어서 하기 →
 [⊕  메시지 입력…            →]  ∿
```

- 魔法师 = front_desk 的形象（尖帽、长发、长袍），只有 scene 1 手托水晶球。
- 推荐句只有 PDF 画的两类：问今天怎么样、接着上次学的。点了 = 替你发出那句话；带 `skill_id` 的直接去 scene 4。
- 一开始打字，推荐句消失。
- 没有课程时：水晶球里显示 `?`，推荐句换成 `배우고 싶은 걸 말해 주세요 →`（点了只把光标放进输入框）。

### Scene 2 · 点去技能树

```
          ●──→○──→○
         ↗        ↘          ← 节点 = 圆点 + 旁边的标题；箭头 = 边
        ●   ○──→●
   👋 AVATAR(小)   도전할 노드를 눌러 주세요!
 [노드 검색…                  →]
```

- **网状图，不是分组框。** 圆点颜色：掌握 = 绿，最近一次审计失败且未掌握 = 红，可挑战 = 白底黑边，锁住 = 浅灰。
- 显示最新的课程；搜索跨所有课程，回车或 → 打开第一个匹配节点（scene 4）。
- 点圆点 → scene 4。左上角 `←` 回 scene 1。

### Scene 4 · 节点总览

```
 node: 이차방정식
 ┌ contents ─────────────┐
 │ 설명 …                  │       AVATAR 👋
 │ https://…              │       도전해 볼까요?  →     ← 点 → scene 4-1
 │ https://youtube…       │
 │                      > │
 └───────────────────────┘
 [ 이 노드에 대해 물어보기…   →]  ∿
```

- contents：节点说明 + 资料链接（这个节点以往补充资料检索的结果）+ 课程大纲来源。链接多时右下角 `>` 翻页。
- 锁住的节点：她说 `아직 잠겨 있어요. 「{父节点}」부터 클리어해요.`，没有 →。
- 在这里输入的问题发给对话（端点 18），回答显示在她的气泡里。

### Scene 4-1 · 审计（2026-10-06 改为一列对话）

```
 ← Calculus  [In progress]
        (avatar 76)  Auditor
                     Asks like a beginner, judges like an expert
        ───────────────────────────────────────────
        Auditor
        earlier question (small, grey)
                                   [ your answer ]
        Auditor
        The current question, large, in the display serif?
 [ Explain it in your own words…           →]  ∿
```

- 一列居中（最宽 720），没有右栏。顶上钉着说话的人（小号形象 + 名字 + 在做什么），表情照旧：提问严肃、失败生气、通过开心；Recorder 出场时换成 Recorder。
- 问答从上往下读：之前的问题小号灰字，**当前这一句是页面标题**（展示衬线、`headlineMedium` 字号），你的回答是右侧气泡。发出去的回答立刻出现在列里，下方是思考微光。出错时那一句红字代替当前问题，文字回到输入框。新内容出现时自动滚到底。
- **裁决卡**（判定后出现在列里）：`VERDICT` → 结论 `Cleared.` / `Not yet.`（衬线 `displaySmall`）+ 分数（衬线大数字）→ 通过时 `+N XP` → 评语 → `What was missing` 列出每个 gap（通过但有 gap 时标题为 `Worth a second look`）→ 按钮。通过的卡是 ember 描边。
- **答错**：裁决卡上有墨色按钮 `Make a lesson card`。点了 Recorder 出场问 `What did you misunderstand?`，按钮消失；你在输入栏回答 → `Lesson card created.`，教训卡在下面翻到正面。后台为第一个 gap 检索补充资料，结果出现在 scene 4 的 contents 里。
- **答对**：庆祝卡浮在整个舞台上方（舞台半透明退后）；关掉后裁决卡留在列里。新解锁的节点在 scene 2 里变成可挑战。
- 裁决卡上都有 `Back to node`（回 scene 4）。
- 再挑战：回 scene 4 再点 →。没有模式切换、没有轮次计数。

### Scene 5 · 对话

- **文字**：avatar + 大气泡（她最新的一句）。你的话只出现在右栏。
- **语音**：输入栏变成声波。
- 她的回答带动作时：生成了课程 → 气泡下方 `월드맵 보기 →`（→ scene 2）；打卡完成 → 左栏 summary 刷新；`navigate` → 直接切场景。
- 审计不能从对话里开始。

## 3. 形象

占位：**线条小人**（黑色细线，和手绘稿一样），每个 agent 一个小区别（发型 / 眼镜 / 帽子 / 领结），3D 做好后按 agent 名替换（김수민负责）。

| 表情 | 用在 |
|---|---|
| 微笑 + 挥手 | scene 1、2、4 |
| 平静 | scene 5、Recorder |
| 严肃 | 审计提问中 |
| 生气（乱涂的眼睛） | 判定失败 |
| 开心 | 判定通过 |

## 5. v3 增补（2026-10-02，用户同意："都给我做吧"）

**对话是主角**：右侧面板就是为了突出对话，所以它是完整的聊天面板（Gemini 样式），不是一列日志。

1. **NotebookLM 面板布局**：画布浅蓝灰，左栏 / 舞台 / 聊天面板是三块白色圆角面板，各有标题栏，侧面板可以折叠成一条窄边。标题统一韩文：左栏「내 캐릭터」，聊天面板「대화」（scene 4 为「도전 기록」，scene 4-1 为「심사 기록」），舞台标题为节点名。
2. **Gemini 首页**：水晶球魔法师上方一行渐变问候语（如 `오늘은 무엇을 배워 볼까요?`，有课程时 `「X」, 이어서 해 볼까요?`）；推荐句做成两张并排的 Gemini 卡片。
3. **聊天面板**：你的话右对齐气泡；她的话左对齐、带 agent 小头像 + 名字 + 时间；日期分隔；自动滚动。审计时同样的样式显示本次问答。
4. **舞台上的说话人**：气泡上方写 agent 名字；你发出的最后一句在输入栏上方短暂显示，她回答后淡出。
5. **思考中**：她的气泡里是流动的渐变微光，不再只是三个点。
6. **场景过渡**：淡入 + 轻微上移；返回时反向。
7. **左栏数字**：`Lv 2 · 3/5`、`클리어 4/12`、`컨디션 양호 / 저하 / 기록 없음`；「오늘의 기록」。
8. **审计通过庆祝**：舞台中央浮出庆祝卡片（星光、分数、+XP、升级、新解锁节点 chip）。
9. **教训卡翻牌**：反思提交后，卡片从背面翻到正面，显示标题、正文、误解。
10. **资料显示标题**：scene 4 的资料一行一个，显示标题 + 域名，不显示原始网址。
11. **技能图图例**：左下角四种状态的小图例。
12. **语音模式**：实时声波（随音量）、状态字、实时字幕。

## 6. 人生游戏层（2026-10-05，借鉴 Dan Koe，用户同意）

Dan Koe 把人生当成一局游戏：赌注（anti-vision）、胜利条件（vision）、主线任务（一年目标）、Boss 战（一个月项目）、日常任务（每天的杠杆）、规则（约束），再加上白天的反思提问。映射到 Self-Infinity：

1. **左栏「My character」顶部**：一句身份宣言（`I am the type of person who…`），下面两块可以直接点击编辑的卡片：`Win condition`（vision）和 `Stakes`（anti-vision），然后是 `Main quests`（最多 3 个一年目标，端点 28–31）和 `Rules`（最多 5 条约束）。空着时显示浅色提示语，点一下变输入框，回车或失焦保存（端点 25/26）。
2. **人生树（scene 2，标题 `Life tree`）**：
   - 结构：你在中心 → 你的课程 → 课程的节点。主线任务（一年目标）不是树上的点，只在左边的角色卡里；课程服务哪个主线，在课程节点的卡片里选（`Serves`），没选的就是支线。课程卡片底下有红色的 `Delete course`：弹窗确认，带一个勾选框“同时删除它的 N 个节点、挑战记录和教训卡”。不勾选时课程从人生树、主线和计划里消失，但节点、挑战记录和教训卡都留着（教训卡照常显示）；勾选则一起彻底删除。
   - 上方一排大数字：进度环 `3/22`、`Cleared`、`Progress %`、`Ready`、`Audits`、`Lessons`（手机上只留前三个）。
   - 深色面板里是缓慢 3D 旋转的星座（拖动可以转，悬停暂停并显示名字）。点任意一点，右侧浮出一叠纸卡片：节点的最高分、尝试次数、教训卡数、**审计历史**（日期、通过/失败、分数条）、教训卡、`Take it on`；目标卡显示它下面所有课程的进度；你自己的卡显示身份、胜利条件和赌注。
   - `Tree | Outline` 切换：Outline 是原来那张从左到右的分层图，一次一门课（上方 chip 选课）。
   - scene 1 的水晶球里是同一棵人生树的缩小版。
   - 根节点和分支节点是 **Boss**：地图上是双圈，scene 4 有 `Boss` 标签，通过时庆祝卡写 `Boss cleared!`。
   - 左栏新增 `Daily quests`：今日任务（学习计划的步骤），完成的打勾，点一下进 scene 4；没有计划时显示 `Get today's quests →`（发出 `What should I do today?`）。
3. **白天的反思提问**：打过卡之后，scene 1 第一条推荐变成当前时段的反思问题（7 个时段，见契约 §6）。点它 → Guide 在气泡里问这句 → 你回答 → 存进日志，Guide 回 `Noted. It's in your journal.`。同一时段答过就不再出现。

左栏从上到下：My character（身份 + Win condition + Stakes + Main quests + Rules）→ 三条属性条 → Daily quests → Today。各块可以折叠，默认都展开。


## 7. 账号与新手教程（2026-10-05）

**登录页 = 落地页**（没登录时只显示它，2026-10-06 改；主旨「干净」）：整屏一块夜色面板，示例人生树在里面慢慢转（像背景视频）。顶部只有左边的火花标志 + `Self-Infinity`、右边一个纸色胶囊 `Sign in`。底部纸色从下往上渐变盖住树，上面一行小字（ember 圆点 + `A learning game you win by explaining`）、衬线大标题 `Prove you understand.` / `Watch your tree grow.`、两个按钮 `Get started`（墨色，开注册）和 `I have an account`（描边，开登录）。入场一次：导航从上滑入（0.8s），树淡入并从 1.05 缩回（1.8s），底部依次上浮（0.5 / 0.6 / 0.8 / 1.0s 起），曲线 `Cubic(0.16, 1, 0.3, 1)`。表单是浮在中间的纸卡（手机上是底部弹出），背后夜色半透明遮罩；×、点遮罩、Esc 关闭。表单只有邮箱 + 密码：`Sign in` / `Create an account` 切换、`Forgot password?`。注册后如果要确认邮箱，显示 `Check your inbox`。

**新手教程**（账号第一次进来，或者在 ◎ 菜单里点 `Replay the tutorial`）：魔法师一问一答，每步都能 `Skip`，右上角 `Skip setup` 直接结束。

1. Welcome：`Let's set up your character.`（说明：用自己的话解释，Auditor 判定）
2. Stakes：`A year from now, nothing has changed. What does your life look like?`
3. Win condition：`A year from now, you've won. What does that look like?`
4. Identity：`Finish the sentence.`（输入框预填 `I am the type of person who `）
5. Main quest：`What's one goal that moves you toward your win condition?`
6. First course：`What do you need to learn first for “{quest}”?` 输入主题，或用课纲文件；在聊天里生成（所以对话从这里开始），生成后自动挂到这个 Main quest 下。
   - 输入的主题先给 Course Scout 看（`POST /skills/scout`，带上前面填的 Main quest 和三问）：说得清楚的整理成规范课名直接生成（`so arm 101` → `SO-ARM101 robot arm`）；太模糊的（`idk, a lot of things`）不生成，换成 `Where do you want to start?` 加最多 3 张课程卡（课名 + 为什么对主线有用），点一张就生成那门；也可以改写输入框再试。Scout 失败就按原文生成。课纲文件不经过 Scout。
7. 导览三页：水晶球（显示你刚长出来的树）→ Auditor 判定 → 失败变教训卡。最后 `Enter Self-Infinity`。

第 2–6 步的输入框右侧有麦克风（`Speak your answer`）：点一下开始听写，说的话实时接在已有文字后面，停顿 3 秒或点停止键结束；听写时按钮变成小波形 + 停止键。识别语言和语音模式一样是 `en_US`。设备不支持时提示 `Voice input isn't available on this device.`

每一步按 Continue 立刻保存。重放教程时，第 5 步改的是第一个 Main quest，不会新建。

**◎ 菜单**（左栏左下角）：当前账号邮箱（本地模式显示 `Local mode (no account)`）、`Replay the tutorial`、`Sign out`。
